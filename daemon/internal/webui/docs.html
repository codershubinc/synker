Quazaar Synker API Documentation

This document outlines the core REST API endpoints exposed by the synkerd server.

Authentication

Several endpoints require an authentication token, which is passed in the headers.

Authorization: Bearer <auth_token>

(Alternatively, you can use X-Sync-Token: <auth_token>)

1. Authentication Endpoints

POST /api/v1/login

Exchanges the server admin password for an authentication token.

Request Body (JSON): 
{
  "password": "admin123"
}
Response (200 OK): 
{
  "status": "success",
  "auth_token": "a1b2c3d4e5f60718293a4b5c6d7e8f9a"
}

2. Sync Endpoints

POST /api/v1/sync Requires Auth

Uploads new listening history from a client to the server. The server strictly validates this data and adds +1 to plays only if the play instance is truly new.

Headers: 
Authorization: Bearer <auth_token>
Request Body (JSON): 
{
  "device_id": "66ea79e8b0ae68c9",
  "device_name": "OnePlus CPH2619",
  "total_seconds": 103246, 
  "total_plays": 460, 
  "tracks": [
    {
      "song_id": "f5053ef4c86fad5a",
      "title": "Galawar Khali",
      "artists": ["Unknown Artist"],
      "album": "Unknown Album",
      "play_count": 14,
      "total_seconds": 350,
      "last_played": 1791487060220,
      "artwork_data": "base64_encoded_jpeg_string..."
    }
  ],
  "plays": [
    {
      "song_id": "f5053ef4c86fad5a",
      "title": "Galawar Khali",
      "artists": ["Unknown Artist"],
      "album": "Unknown Album",

    {

{
  "status": "success",
  "synced_tracks": 1,
  "synced_plays": 1
}
GET /api/v1/sync/pull Requires Auth

Pulls the complete aggregated listening history from the server to restore a client database.

Query Parameters:
  • device_id: The ID of the device requesting data.
Response (200 OK): 
{
  "device_id": "66ea79e8b0ae68c9",
  "device_name": "OnePlus CPH2619",
  "total_seconds": 103246,
  "total_plays": 460,
  "tracks": [...],
  "plays": [...]
}

3. Data & Dashboard Endpoints

GET /api/v1/state

Returns the complete structured music database, including all devices, aggregated history, and tracks.

Response (200 OK):
