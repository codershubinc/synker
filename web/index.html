ARCHITECTURE

Built for Performance, Privacy & Precision.

Decentralized synchronization engineered in Go and Kotlin without third-party vendor lock-in.

📱

Android Client (klient)

Native Jetpack Compose mobile client. Silently captures Apple Music notification telemetry, tracks local play counts, and offers 1-tap JSON backups.

⚡

Go Daemon (synkerd)

Lightweight Linux background service. Ingests high-frequency WebSocket ticks, maintains an embedded SQLite database, and auto-discovers peers via mDNS.

🖥️

Desktop MPRIS Hook

Full Linux D-Bus MPRIS player registration. Control playback and view current phone playback directly from Waybar, Polybar, GNOME, or KDE.

🎨

Lossless Artwork Pipeline

Transmits and caches 100% original-quality album art tied deterministically to song IDs, eliminating stale covers and redundant uploads.

🌐

P2P LAN + Cloud Fallback

Zero-config local discovery on your home Wi-Fi with intelligent subnet proximity matching, plus automatic encrypted tunnel fallback when away.

🔄

Native Auto-Updates

Built-in self-updaters for both the Android app (via FileProvider) and Linux daemon (atomic binary swap via synkerd update).

🚀 Fast Installation

Download, compile, and configure the user-level systemd service in seconds:

$ curl -fsSL https://raw.githubusercontent.com/codershubinc/synker/main/install.sh | bash

Direct executable management and updates:

$ synkerd status # Check daemon health & mDNS
synkerd update # Self-update binary from GitHub
